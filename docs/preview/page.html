Layout & appearance

Layout changes preserve playback time. Width controls terminal drawing space, not zoom. Activity text uses Pi's separate editor divider, so it does not consume animation width. The web preview scales down to fit each card without changing the terminal layout.

One shared clock. Pause and scrub to inspect a pose; expand a card for a closer look. Space toggles playback.

This offline page never changes your Hush settings or loads network resources. Rebuild it after animation edits.
Colours use preview palettes; terminal fonts and your Pi theme can look slightly different.
